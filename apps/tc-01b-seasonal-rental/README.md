# TC-01B — Seasonal Rental Care

## Objective

Explore verification and care for seasonal and vacation rental transactions.

## Initial workflow

```
Rental URL
→ property
→ offer
→ counterparty
→ evidence
→ cross-checks
→ risk signals
→ pre-payment checklist
```

## Initial checks

- existence of the property;
- address/location consistency;
- identity of the offering party;
- authority/relationship to the offer where evidence is available;
- image/content consistency;
- price and condition consistency;
- payment conditions;
- cancellation/refund conditions;
- contact information;
- pressure or anomaly signals.

The system should present evidence and unresolved questions rather than declare an offer fraudulent or safe.
