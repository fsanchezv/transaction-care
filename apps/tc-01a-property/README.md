# TC-01A — Property Care

## Objective

Explore verification and care for residential property transactions.

## Initial workflow

```
Property/offer URL
→ entity extraction
→ counterparty/property evidence
→ consistency checks
→ risk signals
→ decision-support report
```

## Initial checks

- property identity;
- location;
- counterparty identity;
- offer consistency;
- available evidence;
- relevant transaction conditions.

No definitive fraud or safety verdict should be produced in the initial version.
